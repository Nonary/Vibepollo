# Vibepollo 1.18.3-beta.1 - 2026-07-24

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/29

## Fixes
- Improved Web UI scrolling performance in Firefox and fixed CSRF allowed origins not being saved.
- Fixed per-user Playnite extension detection and installation.
- Fixed delayed WebRTC connection setup through Traefik and Cloudflare proxies.
- Fixed WGC startup after DPI-awareness warnings, reduced WGC-related game frame drops, and prevented a capture crash after shader compilation failures.
- Improved virtual-display restoration and installer repair recovery from stale Windows driver or broker state.
- Made game detection follow visible desktop UI, so background games and passive compositor surfaces no longer keep RTX HDR and adaptive-refresh policies active over desktop use.
- Restored HEVC Main10 HDR streaming on affected Radeon Pro 5500 XT systems.
