# Vibepollo 1.19.0-alpha.2 - 2026-08-13

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/59

## Changes
- Added Remote Monitor sessions for up to four Moonlight clients. Launch Remote Monitor from Moonlight on another device to use it as an independently arranged extra display alongside the primary game stream; launch Remote Input when that client should control the host without receiving video.
- Added a confirmation-protected Terminate control that ends the shared game without disconnecting attached Remote Monitor or Remote Input sessions.

## Fixes
- Fixed headless startup failing to discover usable encoder capabilities when no interactive desktop was available.
