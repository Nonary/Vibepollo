# Vibepollo 2.0.1-beta1 - 2026-10-08

## Changes

- Replaced the Playnite 10 PowerShell connector with a compiled .NET extension while preserving game status, library snapshots, and launcher handoff. Connector settings control whether it runs, sends library changes to Vibepollo, and writes verbose logs.

## Fixes

- Made Playnite connector shutdown and upgrades more reliable, and restored SDK discovery and visibility of legacy plugin upgrades.
- Fixed Steam artwork discovery and downloads for newer apps whose portrait files are stored in content-hash directories.
- Allowed display rotation settings through the Linux session broker.
- Updated the Windows virtual gamepad driver to libvirtualgamepad 0.1.0-beta.7, fixing GameInput/native HID device identity handling.
