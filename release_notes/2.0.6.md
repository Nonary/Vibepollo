# Vibepollo 2.0.6 - 2026-11-02

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes

- Restored the Windows setup bootstrapper and MSI install actions from 2.0.1 after reports of installation and upgrade failures with the newer installer security checks.
- The newer installer security checks and permission repairs remain on Canary for extended testing in nightly builds before returning to stable releases.
- The installer no longer deletes every `.txt` and `.log` file in the install folder during migration.

This rollback affects the Windows installer. Other application and driver updates remain in place. Linux behavior is unchanged.
