# Vibepollo 2.0.6 - 2026-11-02

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes

- Fixed the Windows installer stopping over things that did not matter, including your own images in the install folder, unusual drive permissions, leftover files from an earlier failed upgrade, and old uninstall entries. It now stops only when an install cannot work or would damage another application's files, and warns only about serious problems.
- Installing outside Program Files is allowed again.
- The installer now fixes install-folder permissions for you, removing write access that every account on the PC would otherwise have. Your own account's access is left alone.
- Upgrades from 2.0.2 through 2.0.4 now clear what those versions' own checks would refuse, so a file you added no longer blocks the upgrade. A junction or hardlink in the install folder, or unusual `C:\` permissions, can still stop an upgrade from those versions.
- The installer no longer deletes every `.txt` and `.log` file in the install folder during migration.

These fixes affect the Windows installer. Linux behavior is unchanged.
