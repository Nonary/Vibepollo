# Vibepollo 1.18.4 - 2026-08-08

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/59

## Fixes
- Restored exact virtual-display activation on ordinary Windows display topologies, preserving driver-created displays and encoder capabilities when direct activation is unavailable.
- Kept the virtual-display topology active while HDR preparation retries, then fell back to SDR without bouncing the physical desktop.
- Applied explicit HDR display profiles to the physical display when a requested virtual display falls back after setup failure.
- Kept extended virtual displays out of clone groups so Windows accepts exact-target activation.
