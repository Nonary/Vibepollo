# Vibepollo 1.19.0-beta.2 - 2026-08-20

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/59

## Changes
- Made Remote Input and Remote Monitor editable library entries, with artwork and per-entry runtime overrides that apply for each remote session.
- Moved command preparation to Everyday > Automation & scripting and made its editor clearer when no commands are configured.

## Fixes
- Fixed Remote Monitor sessions muting host audio; host playback now remains on while the Remote Monitor audio setting still controls capture and streaming.
- Fixed Lossless Scaling for generic Playnite launches, so saved scaling-only profiles apply and the game executable is not mistaken for the Lossless Scaling launcher.
- Restored the global virtual-display setting for legacy app profiles unless they explicitly select a display.
- Restored the legacy Web UI’s ability to retrieve current release details from GitHub.
- Removed an unused ViGEmBus force-uninstaller from the installer to avoid leaving a manually installed ViGEmBus driver partially removed.
- Reduced Windows trust prompts during signed virtual-display driver upgrades.
- Improved restoration of physical monitor layouts after virtual-display sessions, avoiding incomplete layouts replacing the last working layout.
