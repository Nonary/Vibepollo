# Vibepollo 1.18.4-beta.3 - 2026-08-07

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/59

## Fixes
- Activated newly created temporary virtual displays before capture so Windows exposes the exact session target during display enumeration.
- Removed idle temporary encoder-probe displays after all concurrent probes release them, without tearing down a target still in use.
- Reset retained HDR state for SDR virtual streams to prevent black capture after an HDR session.
- Kept physical-display restoration pending when a required saved monitor is unavailable instead of accepting an incomplete fallback.
