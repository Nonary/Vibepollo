# Vibepollo 2.0.5 - 2026-11-01

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes

- Made drive-root ownership and permission findings diagnostic-only, without warnings or installation blocks when the installation folder is safe.
- Fixed Windows installer rejections caused by custom images, unrelated files, or unrelated links inside an existing installation folder. Checks now focus on packaged files, installer action inputs, and their parent folders.
- Fixed validation of configuration-migration folders, short filenames, and the actual file locations used by older installations during upgrades and repairs.
- Improved rejection reports with the exact affected path, ownership and permission details, and the failed Windows operation so installation failures can be diagnosed from the collected logs.

These fixes affect the Windows installer. Linux behavior is unchanged.
