# Vibepollo 1.18.3-beta.3 - 2026-07-25

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/29

## Fixes
- Fixed fullscreen game-detection issues affecting adaptive refresh-rate switching and RTX HDR: both remain enabled through borderless game overlays, while genuine desktop UI and expired game state reliably return the display to desktop behavior.
- Preserved fractional frame-rate limits and exact RTSS settings when streams end.
- Prevented virtual-display recovery and shutdown watchdog work from outliving a stream or shutdown.
