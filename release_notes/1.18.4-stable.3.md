# Vibepollo 1.18.4-stable.3 - 2026-08-18

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/59

## Fixes
- Fixed unnecessary work on the v2 display-helper fast path and switching between helper engines.
- Fixed virtual-display activation waiting on unstable monitor identity, recovery-state cleanup making the host unreachable, and stale portrait pointer rotation after restore.
- Fixed Steam audio device ownership and restoration across app resumes and interrupted endpoint visibility changes.
- Fixed Lossless Scaling launcher selection so a game path cannot be launched as the scaling tool.
- Defaulted AMD encoding to the supported FFmpeg AMF path while keeping native AMF as an explicit experimental option.
