# Vibepollo 2.0.4 - 2026-11-01

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes

- Fixed a Windows installer security check that rejected valid drive-root permissions on some systems. Made uncertain compatibility checks warn instead of blocking installation. Critical failures now report the affected path, check and Windows error in the installer and logs, and are checked before removing the working installation. Linux was unaffected.
