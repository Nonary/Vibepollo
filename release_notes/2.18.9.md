# Vibepollo 2.18.9 - 2026-11-19

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes

- Used a GPU copy before CPU upload when KMS capture cannot import a KWin framebuffer directly. Sign out and back in once, or reboot, to load the replacement bridge. GPU fallback works before that restart.
- Fixed certificate setup and pairing compatibility with OpenSSL 4.
- Kept WASAPI audio capture timestamps continuous through sample timing jitter.
- Stopped DualSense rumble when gamepad emulation is disabled.
- Fixed UPnP gateway detection with newer MiniUPnPc versions.
- Released the Linux Avahi client when its event loop stops.
