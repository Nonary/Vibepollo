# Vibepollo 1.18.4-beta.1 - 2026-08-06

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/29

## Fixes
- Updated libvirtualdisplay to v1.6.3 so a failed virtual-display teardown no longer blocks later virtual-display creation.
- Prevented completed sessions from reviving stale virtual-display recovery while the physical desktop is being restored.
- Ensured virtual-display DPI changes target only verified virtual monitors, never the Windows primary physical display.
- Deferred idle display probing and topology readiness checks until the interactive desktop or requested topology is actually ready, avoiding stuck temporary displays at startup.
- Preserved automatic and fractional display refresh-rate policies, including across delayed virtual-display activation.
- Kept encoder-probe ownership tied to the captured GPU and restored display topology before releasing retained virtual targets.
- Normalized Playnite autosync identifiers so existing entries are not missed or purged because of letter-case differences.
