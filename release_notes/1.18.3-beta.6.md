# Vibepollo 1.18.3-beta.6 - 2026-07-27

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/29

## Changes
- Completed Web UI translations for all 19 supported non-English locales and improved layouts for longer localized text.
- Made the recommended virtual-display scale adapt to client resolution while preserving Automatic and explicit scale selections.

## Fixes
- Kept adaptive refresh-rate switching and resumed WGC and RTX HDR streams responsive across concurrent sessions and display-helper changes, while keeping RTX HDR source displays in SDR.
- Hardened Windows audio teardown and endpoint restoration so stuck recovery calls cannot hang the host, each endpoint role restores independently, and stale recovery work cannot overwrite a later stream or user choice.
- Kept 10-bit SDR on the SDR capture path and limited it to compatible per-client opt-ins, and restored AMD AMF HDR10 startup by avoiding unsupported PreAnalysis combinations.
- Prevented virtual-display recovery from starting overlapping driver restarts and stopped normal Settings and Dashboard loads from stalling on stale display paths.
- Corrected per-app controls for numeric frame limits and string-backed booleans, and kept paired-client lists current after pairing.
- Preserved UTF-8 names, JSON array structure, launch commands, and release-ordered executable versions during installer upgrades, with narrowly scoped recovery for known firewall-cleanup failures.
- Fixed Playnite cleanup, quit, and synchronization edge cases so resumed games stay alive, explicit quits complete promptly, and manually linked metadata refreshes when autosync is disabled.
