# Vibepollo 1.18.3-beta.4 - 2026-07-25

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/29

## Changes
- Added a native AMD AMF encoder on Windows for H.264, HEVC, and AV1 with SDR/HDR support, dynamic bitrate, bounded recovery, live HDR metadata updates, graceful software fallback, and an explicit legacy encoder rollback option.

## Fixes
- Prevented alt-tab and opaque-overlay activity from freezing active streams or unnecessarily disabling adaptive refresh-rate switching and RTX HDR.
- Improved virtual-display startup by waiting for the requested HDR state, keeping nominal 60 Hz separate from explicit fractional rates, and bounding failed v2 verification instead of leaving capture black for minutes.
- Fixed NVIDIA Smooth Motion activation and pacing when driver profile settings were inherited or defaulted.
- Kept Playnite game cleanup active through installer upgrades.
