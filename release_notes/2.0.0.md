# Vibeshine 2.0.0 - 2026-09-28

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Changes
- Brought Vibeshine to Linux, with support for Arch Linux and CachyOS on KDE Plasma Wayland, including virtual displays, HDR streaming, and Steam and Lutris libraries.
- Added Remote Monitor so additional Moonlight devices can use independent displays alongside the primary game stream.
- Added native DualSense support, including wireless haptics and adaptive triggers on Linux when paired with the [VRR Moonlight Client](https://github.com/Nonary/moonlight-qt) on Linux.
- Added opt-in PyroWave encoding for compatible clients on high-bandwidth wired networks, with GPU encoding on Linux and Windows.

## Fixes
- Preserved Remote Monitor and Remote Input sessions when games ended, while releasing the game's virtual displays and runtime settings.
- Prevented stale Windows virtual gamepad reports from replaying released buttons and triggers.
- Kept installer actions accessible on smaller Windows screens and protected WebRTC source cleanup from drive-root paths.
- Restored Steam artwork synchronization when a valid PNG does not need transcoding.
