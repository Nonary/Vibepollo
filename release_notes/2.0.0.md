# Vibepollo 2.0.0 - 2026-09-28

Vibepollo 2.0.0 brings a native Linux host in beta, smoother VRR streaming, PyroWave, and Remote Monitor sessions together in one release.

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented in [issue #59](https://github.com/Nonary/Vibepollo/issues/59).

## What's new

- **Linux host for Arch Linux and CachyOS (beta).** The native package runs Vibepollo as machine-wide services on KDE Plasma 6 Wayland. Managed private virtual displays support HDR, GPU-resident capture, and Remote Monitor sessions without dummy plugs. NVIDIA hosts can also stream and pair from the login screen; AMD and Intel hosts start streaming after desktop login. The signed pacman repository, DKMS driver, and installer script handle normal installation and updates. CachyOS is the main development platform; testing has focused on NVIDIA and modern AMD GPUs, and older cards may not work properly.
- **Better VRR capture on Windows and Linux.** On Windows, a VRR-capable client automatically selects a fixed 1000 Hz virtual-display mode, so newly presented game frames can be captured promptly without increasing the stream frame rate. Windows Graphics Capture timing now follows game presentation more closely, including uneven callbacks. On Linux, managed virtual displays use presentation-driven capture and improved pacing to deliver new frames without unnecessary polling or duplicate waits. For VRR playback, use a client with VRR pacing such as the [VRR Moonlight Client](https://github.com/Nonary/moonlight-qt).
- **PyroWave on Windows and Linux.** A compatible client can request this GPU wavelet codec for very low encode and decode latency. Frames are independent, so losing one does not require a new keyframe. The host supports SDR and HDR, 8-bit and 10-bit color, and 4:2:0 and 4:4:4 profiles when the GPU and capture path support them. Linux's NvFBC capture path does not support PyroWave. PyroWave needs a fast **wired LAN** with hundreds of Mbps available; standard H.264, HEVC, and AV1 streaming remains available. See the [PyroWave guide](https://github.com/Nonary/Vibepollo/blob/2.0.0/docs/pyrowave-protocol.md) for compatibility and bandwidth details.
- **Remote Monitor and Remote Input.** Launch **Remote Monitor** from Moonlight on another device to turn it into an additional, independently streamed display beside your main session. Up to four Moonlight clients can connect. **Remote Input** attaches a client for control without video. Remote Monitor entries can have their own settings, and the Web UI lets you manage audio and disconnection behavior, plus per-client layout on Windows.
- **Linux game integration and color controls.** Steam and Lutris games can synchronize into Vibepollo's library with artwork and configurable recent-game policies. Steam Big Picture launches from the desktop session, while Proton games can use managed frame limiting and stream-scoped HDR compatibility. NVIDIA hosts can also use Smooth Motion for supported game launches. Per-application 10-bit SDR preferences keep the chosen color mode when a game resumes.
- **More controller and audio support.** Vibepollo's Windows virtual gamepad driver can present Xbox, DualSense, DualShock 4, and Switch Pro profiles without requiring ViGEmBus. Linux adds DualShock 4 emulation and wireless DualSense haptics and adaptive triggers when both the host and [VRR Moonlight Client](https://github.com/Nonary/moonlight-qt) run Linux. Proton DualSense compatibility is enabled by default, with a Web UI toggle and per-game overrides. Windows audio capture can leave the system's default playback device in place.

## Fixes

- Preserved Remote Monitor and Remote Input sessions when games ended, while releasing the game's virtual displays and runtime settings.
- Prevented stale Windows virtual gamepad reports from replaying released buttons and triggers.
- Kept installer actions accessible on smaller Windows screens and protected WebRTC source cleanup from drive-root paths.
- Restored Steam artwork synchronization when a valid PNG does not need transcoding.

## Quick start

**Windows**

1. Download and run the Windows installer from the [2.0.0 release assets](https://github.com/Nonary/Vibepollo/releases/tag/2.0.0). Open <https://localhost:47990> on the host, create your Web UI login, and pair a Moonlight client with its PIN.
2. Select a virtual display in the Web UI for managed capture. If your client requests VRR pacing, the Windows virtual display uses the 1000 Hz capture mode automatically; the game and stream still target the client's requested frame rate.
3. To use an extra screen, launch **Remote Monitor** from Moonlight on a second device. To try PyroWave, use a compatible client, choose PyroWave as its codec, and connect over a fast wired LAN.

**Arch Linux and CachyOS (beta)**

You need **x86_64**, **Linux 6.16 or newer with headers matching the running kernel**, **KDE Plasma 6 on Wayland started by SDDM or Plasma Login Manager**, and a GPU with hardware H.264 encoding. Testing has focused on NVIDIA and modern AMD GPUs; older cards may not work properly. The native beta does not ship AppImage, Flatpak, Debian, Fedora, or Docker packages. Pre-login streaming requires NVIDIA.

```bash
curl -fsSLO https://raw.githubusercontent.com/Nonary/Vibepollo/2.0.0/scripts/linux_install.sh
sudo bash linux_install.sh --no-repo --version 2.0.0
```

The script checks requirements, installs matching kernel headers and the exact 2.0.0 GitHub release package with pacman, configures an active firewalld or ufw firewall, and prints the remaining steps. **Reboot after the first installation** so the display driver and login-session integration are ready. If installation requests Secure Boot key enrollment, approve it during that reboot. Then log in to Plasma Wayland, open <https://localhost:47990> on the host, create your Web UI login, and pair Moonlight. The new login also activates Vibepollo's PipeWire audio configuration. For signed repository setup, multiple desktop users, upgrades, and troubleshooting, follow the [Linux install guide](https://github.com/Nonary/Vibepollo/blob/2.0.0/docs/linux/install.md).
