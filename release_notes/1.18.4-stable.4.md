# Vibepollo 1.18.4-stable.4 - 2026-09-09

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Fixes
- Fixed incomplete physical-monitor restoration after virtual-display sessions, keeping missing monitors pending and preserving the last verified layout when recovery fails.
- Fixed headless startup failing to discover usable encoder capabilities before an interactive desktop is available.
- Fixed virtual capture selecting the wrong monitor when multiple virtual displays change enumeration order.
- Restored global virtual-display inheritance for legacy app profiles while preserving explicit per-app display choices.
- Fixed scaling-only Lossless Scaling profiles being ignored for generic Playnite launches.
- Fixed large troubleshooting log exports blocking the Web UI or timing out.
- Restored the legacy Web UI's ability to retrieve current GitHub release details.
- Added an explicit opt-in for configured RTSS limiter modes on virtual displays while retaining the default Reflex behavior.
- Fixed command-editor labels, removal-button accessibility, and empty-state clarity in the v2 Web UI.
- Reduced Windows trust prompts during signed virtual-display driver upgrades while preserving existing legacy trust and unchanged driver payloads.
- Removed the unused ViGEmBus force-uninstaller to avoid leaving a manually installed driver partially removed if the script is run.
- Fixed out-of-tree builds producing an incorrect 0.0.0 version and TrueHDR runtime staging deleting existing build outputs.

These fixes were backported from 1.19.0-beta.1 and 1.19.0-beta.2, published August 20 and August 21, respectively, after at least one week in beta.
