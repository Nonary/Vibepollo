# Vibepollo 1.19.0-beta.1 - 2026-08-19

Notice: Vibepollo may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/Vibepollo/issues/59

## Changes
- Added Vibepollo's own virtual gamepad driver as an alternative to ViGEmBus, selectable from the gamepad setting. It can present an Xbox Series or Xbox One controller, a DualSense, a DualShock 4, or a Switch Pro Controller, and the automatic option picks one to suit the connecting client. The Xbox options are the ones Windows places on the XInput path, so they are what games supporting only XInput can see; the PlayStation options add the touchpad, motion sensors, battery reporting, the light bar, and adaptive triggers on DualSense. The installer offers to install the driver, and ViGEmBus is no longer reported as missing when this driver is providing controllers.
- Added Remote Monitor lifecycle options and surfaced them in the Everyday view, so a Remote Monitor session can be managed without opening advanced settings.
- Added a virtual display kill switch for recovering a host whose virtual display is misbehaving.

## Fixes
- Fixed a crash that could occur when Steam changed audio endpoint visibility mid-session.
- Fixed audio capture losing ownership of the sink when an app resumed, and made the handoff back to the terminal session ordered so a reconnect no longer raced it.
- Fixed AMD hosts defaulting to an encoder path that underperformed; AMD encoding now defaults to FFmpeg.
- Fixed virtual capture affinity being lost while a stream was active.
- Fixed remote sessions not honoring terminal session boundaries.
