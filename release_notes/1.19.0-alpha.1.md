# Vibeshine 1.19.0-alpha.1 - 2026-08-11

Notice: Vibeshine may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/Nonary/vibeshine/issues/59

## Changes
- Added concurrent multi-monitor streaming, allowing additional Moonlight clients to connect as independent remote displays without interrupting the primary stream.
- Added input-only remote sessions and per-client monitor layout controls for arranging streamed displays alongside physical or virtual desktops.

## Fixes
- Fixed display helper changes not taking effect reliably after switching display engines.
- Fixed display recovery using unstable monitor identities, stale rotation state, or incomplete recovery data.
- Improved troubleshooting log exports so large reports no longer block the Web UI.
