# Bazzite port status

Experimental support works on one Bazzite NVIDIA Open 44 / RTX 5080 machine
with Secure Boot enabled and SELinux enforcing. See [README.md](README.md) for
the tested configuration, local build and setup steps, and remaining work.

The consolidated checkout still needs a clean build/install rerun. Kernel
updates, uninstall/recovery and broader qualification remain open. All builds
stay local; this proposal adds no hosted Bazzite workflow.
